## 4.0.3 — обновления ставятся в папку лаунчера

О лаунчере: вкладка О лаунчере теперь содержит пункт Автообновления — релизы выходят на GitHub (github.com/Dooyfil/FirmyLauncher), проверяются по SHA-1, ставятся в папку лаунчера.

Фикс обновления: NSIS-установщик вызывается с /D=<app path> — обновление ставится в папку, где лежит запущенный лаунчер, а не в AppData\Local\Programs.
# Changelog

## 4.0.3 — обновления ставятся в папку лаунчера

- **Фикс обновления**: NSIS-установщик теперь вызывается с параметром `/D=<app path>` — обновление ставится в папку, где лежит запущенный лаунчер, а не в `AppData\Local\Programs\FirmyLauncher`.
- **Версия 4.0.3**.

## 4.0.2 — манежение обновлений из GitHub (фикс sha1 case)

- Обновление из GitHub: `Dooyfil/FirmyLauncher` — релиз `v4.0.2` с установщиком `FirmyLauncher-Setup-4.0.2.exe`.
- Исправлена ошибка `SHA-1 mismatch` (хеш сравнивался с разным регистром — ключевой фикс периодических ошибок при обновлении).

## 4.0.1 — автоматические обновления из GitHub

- Установщик проверяет SHA-1 перед установкой.
- Гайд в README.md — установка, все возможности и функции.
