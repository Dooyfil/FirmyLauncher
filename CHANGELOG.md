# Changelog

## 4.0.1 — автоматические обновления из GitHub

**Что изменилось:**

- **Установщик в релизы** — FirmyLauncher-Setup-4.0.1.exe выложен как ассет GitHub-релиза [v4.0.1](https://github.com/Dooyfil/FirmyLauncher/releases/tag/v4.0.1).
- **Манифест обновлений** — файл `updates/latest.json` в этом репозитории: версия, ссылка на установщик, SHA-1 и описание возможностей.
- **Авто-проверка обновлений в лаунчере** — при запуске и через периодический таймер (раз в 15 мин). Проверка идёт по URL из настроек лаунчера (по умолчанию — манифест из этого репозитория).
- **Установщик проверяет SHA-1** перед установкой — оском, описанная в манифесте.
- **Гайд в README.md** — установка, все возможности и функции.
- **Переезд на GitHub** — все релизы и репозиторий обновлений теперь на GitHub (Dooyfil/FirmyLauncher).

**Фолбэки остались в коде:** если GitHub недоступен, лаунчер использует кэшированные данные и статические списки.
