**FirmyLauncher** — современный Electron-лаунчер для Minecraft: все версии Mojang, Java-панель, магазин Modrinth, мониторинг серверов, скриншоты, автообновления.

---

## 🚀 Установка

### 1. Скачай установщик

Свежий официальный установщик обычно есть на странице [Релиза](https://github.com/Dooyfil/FirmyLauncher/releases) или внизу страницы — `FirmyLauncher-Setup-4.0.2.exe`.

> Обновления проверяются прямо в лаунчере — при запуске и периодически. Будущие релизы выходят как GitHub-релизы и находятся здесь, в этом репозитории: https://github.com/Dooyfil/FirmyLauncher/releases

### 2. Запусти установщик

Открой скачанный файл. Дождись проверки целостности (SHA-1) и выбери папку для установки — рекомендуется `C:\Users\<твой-аккаунт>\Desktop\FirmyLauncher` или любая удобная папка.

### 3. Запусти FirmyLauncher

В окне лаунчера первый запуск запросит никнейм. После этого:

- Выбери версию Minecraft — будет видна сразу вся каталогизация от 1.0 до 26.3.
- Нажми **«Играть»** — установка происходит автоматически, с выбором Java-ранта под версию.

## ✨ Что умеет FirmyLauncher

### 🌍 Все версии Minecraft

Каталог версий обновляется с серверов — видны все официальные релизы **от 1.0 до 26.3**, а также старые беты и альфы (фильтр в меню версий: Релизы / Беты / Альфы). Статический фолбэк есть для офлайн-ситуаций, но реальные списки работают онлайн.

### ☕ Умная Java

Java-панель: подбирается оптимальный рантайм на выбранную версию. Установленные рантаймы: 8, 16, 17, 21, 25 — пропаздываем с того, чтобы вручную скачивать по клику «Проверить все».

### ⚙️ Модлоадеры из сети

- **Fabric** — поддерживаемые версии от 1.14 до 26.3
- **Forge** — версии с 1.5.2 до 26.3
- **OptiFine** — за отдельной кнопкой на версии

Списки фетчятся из сети, поэтому никаких лишних установков — скачал, выбрал, нажал «Установить». В фильтре модлоадеров видно количество версий под версию Minecraft.

### 📦 Магазин Modrinth

Прямо в лаунчере — поиск по модам, ресурспакам, шейдерам: фильтры клиент/сервер, рейтинг, дата, центр компатибилинесса с твоей версией, установка в один клик.

### 🗄 Контент под версии

Моды, шейдеры, ресурспаки и настройки сервера хранятся по отдельным папкам — `.minecraft/content/<имя>` — чтобы не конфликтовать между версиями и модлоадерами. Быстрое синхронизирование контента с глобальной папкой игры.

### 🌐 Мониторинг серверов

Таб **Серверы**: онлайн, пинг, MOTD — снапшот каждые 60 секунд. Панель статистики: общий онлайн, средний пинг, топ-5 по онлайну. Двойной клик — копируем адрес, один клик — показываем MOTD.

### 📸 Скриншоты

Нажми F2 — кадр автоматически попадает в `.minecraft\screenshots`. В лаунчере — галерея со всеми кадрами игры. Можно открыть папку игры в один клик.

### ⚙️ Настройки лаунчера

Низ лаунчера: выбор аккаунта (через Microsoft), выбор папки игры, выбор версии для запуска, запуск в автономном режиме, выбор времени перезапуска, настройка карты сервера.

### 📝 О лаунчере

Вкладка с полной историей изменений по каждой версии от 1.0 до текущей — что было изменено, новые возможности, производительность, специальные заметки.

### 🔄 Автообновления

- Проверка обновлений при запуске лаунчера и по таймеру.
- Манифест обновления живёт на GitHub: [Dooyfil/FirmyLauncher](https://github.com/Dooyfil/FirmyLauncher/releases) — каждый релиз идёт с установщиком, контрольная сумма проверяется перед установкой.
- Установщик запускается тихо — лаунчер закрывается после установки.

### 💚 Фирменная политика

- **Бесплатно** полностью — без подписок, премиум-возможностей, телеметрии.
- **Безопасность** — все списки версий и модлоадеров проверяются через TLS и серверы Mojang, Minecraft Forge и Modrinth.
- **Автономный** — если сеть упала, лаун�чер всё ещё использует кэшированные данные и статические фолбэки.

## 🛠 Сборка из исходников

```powershell
# 1. Зависимости
cd .\FirmyLauncher
npm install

# 2. Сборка
cmd /c scripts\build.bat   # или npm run build, если указан в package.json
```

> При сборке закрой лаунчер — иначе файлы будут заняты.
